# Portfolio description

## Short version

Built a retail sales analytics project using SQLite, SQL, Excel, and Power BI.
Designed a star schema, analyzed revenue and profit trends with joins, CTEs, and
window functions, and created a one-page dashboard for monthly, category, channel,
product, and customer performance. The project uses reproducible synthetic data.

## CV bullets

- Built a SQLite star schema and analyzed more than 1,000 retail sales records using
  SQL joins, aggregations, CTEs, ranking, and month-over-month window functions.
- Created a Power BI-ready model with DAX measures for revenue, profit, margin,
  orders, average order value, active customers, and monthly growth.
- Designed a one-page dashboard covering sales trends, product performance, channels,
  customer segments, and cities using a reproducible synthetic dataset.

## Interview explanation

The project separates dimensions from the sales fact table so the same model can answer
multiple business questions without duplicating product or customer attributes. SQL is
used for validation and exploratory analysis. Power BI is used for interactive filtering,
time intelligence, KPI monitoring, and communication to business users.
